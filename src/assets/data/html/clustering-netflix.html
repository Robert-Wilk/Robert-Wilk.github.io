Introduction¶

Today, we will be movies and TV shows. Many people love to watch shows in their free time. In this notebook, we will take a look at shows and movies on Netflix and try to build a recommendation system using clustering.

What is clustering you might be asking yourself?

Clustering is extacly as it sounds. Group data points with other similar data points. Clustering is an unsupervised machine learning method that tries to learn similarities between data points and reveal hidden relationships.

There are many approaches of clustering but let's look at 2:


Agglomerative Clustering:

Agglomerative Clustering starts with the assumption that all points are clusters. In the algorithm, clusters are compared to find how close they are. If clusters are considered to be close then they are merged into a larger cluster. The algorithm ends when the desired number of clusters are formed. An optimal number of clusters for a given data set can be found using a Dendrogram. (read more)


K-Means Clustering:

K-means Clustering starts with creating K random center points, called centroids. In the algorithm, data points are compared to the centroid. K-Means Clustering tries to learn most optimal placement for each centroid. (read more)


We will be using K-Means Clustering

Training¶

Before we train our model, we need to identify the optimal amount of clusters for our algorithm to create. One way to do this is the Elbow method.


The Elbow method is a graphical tool that shows us the distortion values for K. While using the elbow method, you want to pick the value that splits the large decreases from the small decreases.

In [ ]:
# imports
from sklearn.cluster import KMeans

# calculate distortion for a range of number of cluster
distortions = []

for i in range(1, 11):
  km = KMeans(
    n_clusters=i, init='random',
    n_init=10, max_iter=300,
    tol=1e-04, random_state=0
  )
  km.fit(df_pca)
  distortions.append(km.inertia_)


# plot
plt.plot(range(1, 11), distortions, marker='o')
plt.xlabel('Number of clusters')
plt.ylabel('Distortion')
plt.show()

Let's pick 4 for our K value

def recommender():
  # Grab random entry from our data set
  sample = df_train.sample()
  sample_netflix = df_netflix.iloc[sample.index[0]]

  # find out what cluster it belongs to
  label = y_km[sample.index[0]]

  # pick random movie from cluster
  recommend_show = df_train.loc[np.random.choice(np.where(y_km == label)[0])]

  # Display our selection
  return sample_netflix, df_netflix.iloc[recommend_show.name], label
