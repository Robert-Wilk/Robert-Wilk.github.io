Introduction¶

The problem we will be tackling today is a housing price regression. Given the features/amenities of a house, predict the price that the home sold for. Also, we will be participating in the "House Prices - Advanced Regression Techniques" competition on kaggle, however the main goal is to practice regressions rather than place well.

What is a regression you might be asking yourself?

A regression is a line of "best-fit" that tries to find predict a given features from other features in a dataset. For example, use the feature of house size to estimate/predict house cost.

There are 2 main types of regressions: logistic and linear

  • A Linear regression tries to fit a simple line to the data, where X represents our input(s) and y represents our prediction.
  • A logisitc regression tries to fit a sigmoid line to the data, where X represents our inputs(s) and y represents a class/type.

The line in a logistic regression the barrier between classes/types, while the line in a linear regression gives a number value.

We will be focused on using a linear regression since housing price is a number value and not a class or type.

# Method for trimming out features we do not need
one_side_colnames = []
two_side_pos_colnames = []
two_side_neg_colnames = []

def compute_correlated_df(dataset, corr_matrix, threshold, method):
    col_corr = 0 
    dataset_trimmed = pd.DataFrame()

    for i, val in enumerate(corr_matrix):
      if method == 'one_side':
        if (val < threshold):
          # getting the name of column
          colname = dataset.columns[i]
          one_side_colnames.append(colname)
          # if number of correlating columns 0 then create new DataFrame based on column found
          # else add new column to existing DataFrame
          if col_corr == 0:
            dataset_trimmed = dataset[colname]
          else:
            dataset_trimmed = pd.concat([dataset_trimmed, dataset[colname]], axis=1)
          col_corr += 1

      elif method == 'two_side_pos':
        if val >= threshold and val < 1:
          # getting the name of column
          colname = dataset.columns[i]
          two_side_pos_colnames.append(colname)
          # if number of correlating columns 0 then create new DataFrame based on column found
          # else add new column to existing DataFrame
          if col_corr == 0:
            dataset_trimmed = dataset[colname]
          else:
            dataset_trimmed = pd.concat([dataset_trimmed, dataset[colname]], axis=1)
          col_corr += 1

      elif method == 'two_side_neg':
        if val <= threshold and val > -1:
          # getting the name of column
          colname = dataset.columns[i]
          two_side_neg_colnames.append(colname)
          # if number of correlating columns 0 then create new DataFrame based on column found
          # else add new column to existing DataFrame
          if col_corr == 0:
            dataset_trimmed = dataset[colname]
          else:
            dataset_trimmed = pd.concat([dataset_trimmed, dataset[colname]], axis=1)
          col_corr += 1

      else:
        return dataset

    if col_corr == 0:
      return dataset
    else:
      return dataset_trimmed
